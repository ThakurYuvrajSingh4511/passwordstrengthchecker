PROJECT TITLE: Password Strength Checker (Web Based)

COURSE: BCA Cyber Security

TECHNOLOGY USED:
HTML, CSS, JavaScript

DESCRIPTION:
This web application checks the strength of a password
based on length, uppercase letters, lowercase letters,
numbers, and special characters.

FEATURES:
- Real-time password checking
- Strength progress bar
- Cyber security best practices

HOW TO USE:
1. Open index.html in browser
2. Enter password
3. View strength result

HOSTING:
Can be hosted on GitHub Pages or Netlify

ADVANCED FEATURE:
This project uses Have I Been Pwned public breach database
to check whether a password has appeared in past data breaches.
It uses SHA-1 hashing and k-anonymity to protect user privacy.
